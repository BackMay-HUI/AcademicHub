# 开发日志 - AcademicHub 项目

---

## 项目简介

**AcademicHub** 是一款本地大学生学业与荣誉管理助手，基于 WPF + .NET 开发。

### 核心功能
- 成绩管理（含GPA计算）
- 荣誉档案
- 毕业追踪
- 保研模拟
- Markdown 笔记
- 简历导出
- 深色/主题模式

### 技术栈
- .NET 10.0
- WPF (Windows Presentation Foundation)
- CommunityToolkit.Mvvm (MVVM框架)
- Entity Framework Core + SQLite
- LiveChartsCore.SkiaSharpView.WPF (图表)
- QuestPDF (PDF生成)
- Markdig (Markdown解析)

#### v2.0 - WPF 迁移与单文件发布

**技术架构迁移**
- 从 Python + PyQt5 迁移到 .NET 10 + WPF
- 使用 MVVM 架构模式
- 使用 Entity Framework Core + SQLite 进行数据持久化

**功能更新**
- 保持原有功能：成绩管理、荣誉档案、毕业追踪、保研模拟、Markdown笔记、简历导出
- 保留三种主题支持：浅色/深色/樱花主题

**单文件发布**
- 使用 `dotnet publish` 命令将应用打包为独立 exe
- 配置参数：
  - `PublishSingleFile=true` - 打包为单个文件
  - `SelfContained=true` - 包含 .NET 运行时
  - `RuntimeIdentifier=win-x64` - 指定 Windows x64 平台
- 生成文件位置：`dotnet/src/AcademicHub/bin/Release/net10.0-windows/win-x64/publish/AcademicHub.exe`
- exe 大小约 160MB（包含 .NET 运行时和所有依赖）
