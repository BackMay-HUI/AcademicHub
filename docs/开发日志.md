# 开发日志 - AcademicHub 项目

---

## 项目简介

**AcademicHub** 是一款本地大学生学业与荣誉管理助手，基于 PyQt5 + SQLite 开发。

### 核心功能
- 成绩管理（含GPA计算）
- 荣誉档案
- 毕业追踪
- 保研模拟
- Markdown 笔记
- 简历导出
- 深色/主题模式

### 技术栈
- Python 3.x
- PyQt5 (GUI框架)
- PyQtChart 5.15.7 (图表)
- SQLite (本地数据库)

## 开发记录

### 2026-02-13

#### v1.0 - 项目初始版本
- 创建基于 PyQt5 的桌面应用框架
- 实现 SQLite 数据库存储
- 搭建各功能模块基础结构

#### v1.1 - UI和功能优化
- **学期选项优化**: 将学期列表改为"大一上"、"大一下"等大学阶段形式
- **窗口大小调整**: 默认 1880x1400，最小 1400x1000
- **GPA计算**: 采用标准绩点算法，支持自定义绩点设置

#### v1.2 - 细节优化
- **UI优化**: 增大统计卡片尺寸(220x130)、字体和间距
- **绩点功能**: 添加成绩时可直接输入绩点（选填），表格显示绩点列

#### v1.3 - 界面美化与可视化
- **界面美化**:
  - 渐变背景（浅色/深色模式）
  - 圆角卡片（16px圆角）
  - 阴影效果
  - 增大字体
- **数据可视化**:
  - 使用 PyQtChart 实现图表
  - 成绩管理页面添加"成绩列表"和"成绩分析"标签页
  - 各学期平均成绩柱状图
  - 学分占比饼图
- **新增依赖**: PyQtChart 5.15.7

#### v1.4 - 图表实时更新
- 添加定时器每3秒检测数据变化
- 仅在数据变化时重新渲染图表
- 标签页切换时自动启停定时器（节省资源）

#### v1.5 - 数据导入/导出
- **CSV导入/导出**: 成绩数据支持CSV格式批量导入导出
- **JSON备份**: 完整数据备份（成绩、荣誉、笔记、毕业要求、学生信息）
- **界面更新**: 成绩管理页面添加"导入"和"导出"按钮

## 项目结构

```
academic_hub/
├── __init__.py
├── app.py              # 主应用入口
├── config.py           # 配置（学期、课程类型等）
├── database.py         # 数据库操作
├── pages/
│   ├── grades.py      # 成绩管理
│   ├── honors.py      # 荣誉档案
│   ├── graduation.py  # 毕业追踪
│   ├── graduate.py    # 保研模拟
│   ├── notes.py       # Markdown笔记
│   └── resume.py      # 简历导出
├── widgets/
│   ├── cards.py       # 统计卡片组件
│   ├── charts.py      # 图表组件
│   ├── dialogs.py     # 对话框组件
│   └── navigation.py  # 导航栏
└── utils/
    ├── theme.py       # 主题管理
    └── export.py     # 导出功能
```
